# 나의 달력 (My Calendar)

로컬 브라우저에만 데이터를 저장하는 개인용 달력 웹앱입니다.

## 사용 방법

1. `index.html` 파일을 더블클릭해서 브라우저로 엽니다. (인터넷 연결이 있으면 글꼴이 예쁘게 표시돼요. 없어도 정상 작동합니다.)
2. 좌측 상단 "나의 달력" 로고를 누르면 언제든 오늘 날짜로 바로 이동합니다.
3. 날짜 칸을 클릭하면 하단에 상세 모달이 열립니다.
   - **날짜 색상 표시**: 팔레트를 클릭하면 해당 날짜 칸 전체에 색이 표시돼요(스티키노트 접힘 효과). "–"를 누르면 해제. 이 색은 그 날짜에 등록하는 일정 색상에도 자동으로 반영됩니다.
   - **일정 추가**: 모달 우측 상단의 + 버튼을 누르면 별도의 입력 창이 열려요. 제목/시간/메모를 입력하고 "일정 추가"를 누르세요. 하루에 여러 개 등록 가능합니다.
   - **일정 수정/삭제**: 목록에서 제목을 클릭하거나 연필 아이콘을 누르면 수정, 휴지통 아이콘을 누르면 삭제됩니다.
4. 상단 검색창으로 일정 제목/메모를 검색할 수 있어요.
5. 우측 상단 🌓 버튼으로 다크/라이트 테마를 전환할 수 있습니다.
6. "이동" 버튼 오른쪽의 "색상 지정" 버튼을 누르면 별도의 창이 열려요. 먼저 색상 팔레트에서 원하는 색을 고른 뒤 미니 달력의 날짜를 클릭하면 그 자리에서 바로 색이 칠해집니다(메인 달력에도 즉시 반영). 이 창 안에서는 좌우 화살표로 다른 달로 이동하며 계속 색칠할 수 있고, 지우개(–)로 색을 지울 수도 있어요.
7. 우측 상단 데이터 관리 버튼(⬇️ 아이콘)에서:
   - **📱 이번 달/전체 일정 캘린더에 공유 (.ics)**: 일정의 제목과 메모(내용)를 표준 iCalendar 파일로 만들어, 휴대폰에서는 바로 공유 시트가 열려요. 아래 "휴대폰 캘린더로 옮기기" 참고
   - **이번 달 내보내기 (JSON)**: 현재 보고 있는 달의 일정 + 날짜색상만 JSON으로 저장 (이 웹앱으로 다시 불러오기용)
   - **전체 데이터 내보내기 (JSON)**: 지금까지 저장된 모든 달의 데이터를 JSON으로 저장
   - **JSON 불러오기**: 다른 PC/브라우저에서 내보낸 JSON 파일을 불러와 병합
   - **이번 달 데이터 삭제**: 현재 달의 일정/색상을 모두 삭제

## 휴대폰 캘린더(아이폰 · 갤럭시)로 옮기기

**이 사이트를 휴대폰 브라우저로 직접 열어서** "📱 …캘린더에 공유 (.ics)" 버튼을 누르면, 아이폰(Safari)과 갤럭시(Chrome/삼성 인터넷)에서는 **바로 공유 시트가 뜹니다.** 거기서 "캘린더"(또는 "캘린더에 저장" / "일정 추가")를 선택하면 한 번에 등록돼요. 일정의 **제목, 메모(내용), 날짜, 시간**이 그대로 들어갑니다.

- 공유 시트가 안 뜨는 구형 브라우저라면, 자동으로 `.ics` 파일이 다운로드됩니다. 이 경우 다운로드된 파일을 탭해서 열면 캘린더 앱으로 연결돼요(아이폰은 "추가", 갤럭시는 앱 선택 후 "가져오기").
- **PC에서 내보낸 경우**엔 공유 시트 기능이 없어 파일만 다운로드돼요. 이때는 그 `.ics` 파일을 이메일이나 메신저로 휴대폰에 보낸 뒤, 받은 파일을 탭해서 열면 됩니다.

같은 방법으로 구글 캘린더(calendar.google.com → 설정 → 가져오기/내보내기)에도 그대로 가져올 수 있어요.

## 다른 컴퓨터로 옮기기

1. 옮기고 싶은 달을 화면에 띄운 상태에서 **"이번 달 내보내기"**를 눌러 `calendar_YYYY-MM.json` 파일을 저장하세요.
2. 그 파일을 USB, 메신저, 클라우드 등으로 다른 컴퓨터에 옮깁니다.
3. 다른 컴퓨터에서 같은 `index.html`을 열고, **"JSON 불러오기"**로 방금 옮긴 파일을 선택하면 해당 월의 일정과 색상이 그대로 복원됩니다.

## 데이터 저장 위치

모든 데이터는 브라우저의 `localStorage`에만 저장됩니다. 서버로 전송되지 않으며, 브라우저 저장공간을 지우면(예: 방문 기록 삭제 시 "쿠키 및 사이트 데이터") 함께 사라질 수 있으니 중요한 일정은 주기적으로 "전체 데이터 내보내기"로 백업해두는 것을 추천합니다.

## 파일 구성

- `index.html` — 메인 페이지
- `style.css` — 스타일
- `script.js` — 동작 로직
- `favicon.png`, `favicon-32.png`, `favicon-192.png`, `favicon-512.png` — 파비콘
